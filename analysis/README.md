# Analysis Directory

This directory holds ad hoc inspection and comparison scripts.

- `analyze_*.py`: embedding and optimizer diagnostics.
- `compare_tokenizers.py`, `verify_retok.py`: tokenizer checks.
- `inspect_multi_mapped.py`, `summarize_full.py`: result inspection helpers.

These scripts are not part of the main training/eval pipeline; treat them as
support tooling for debugging and post-run analysis.
