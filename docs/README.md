# Docs Index

Project documents are grouped by purpose:

- `reports/`: experiment writeups and milestone reports.
  Current: `reports/retok_v17.md`, `reports/v18_tie_lineage.md`
- `eval/`: evaluation pipeline and benchmark notes.
  Current: `eval/pipeline.md`
- `plans/`: research loops, playbooks, and execution protocols.
  Current: `plans/autoresearch.md`
- `huggingface_v18_upload.md`: upload checklist for `Qwen3-1.7B-Base-ReTok`.

Use this directory for narrative documents and decision records. Keep raw logs
and machine-generated metrics under `output/` or `eval_results/`, not here.
