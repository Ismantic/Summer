# Summer 的评测依赖。和 requirements.txt 装进**同一个** Python 3.11 venv:
#     uv venv --python 3.11 ~/.venv-e
#     uv pip install --python ~/.venv-e/bin/python -r requirements.txt
#     uv pip install --python ~/.venv-e/bin/python -r requirements-eval.txt
#
# 为什么是 3.11 —— 这几样把版本钉在这儿了(见 docs/WHY.md 第五节):
#   - vllm 没有可用的 cp314 构建
#   - comet 的依赖链(torchmetrics 0.10.3)要 functools._HashedSeq,3.14 里没有
#   - 硬往 3.14 装会把解拽回 vllm 0.2.5(2023 年底,不认识 Qwen3),
#     并连带降级 numpy / pandas / pydantic
#
# 反过来把训练搬到 3.11 完全可以,所以现在就一个 venv。
#
# 训练也用这个 venv —— local.mk 里 PY 和 PY_EVAL 指同一个就行。
# 拆成两个 requirements 文件只是为了说清「哪些是评测才需要的」。
